# Contributing to CFITSIO

Welcome to the CFITSIO project! We appreciate your interest in contributing to the High Energy Astrophysics Science Archive Research Center (HEASARC) software ecosystem. CFITSIO is heavily utilized by the astronomical community, and community contributions help keep it robust and feature-rich.

This document outlines the process for interacting with the team and contributing code to the CFITSIO repository.

## Reporting Security Vulnerabilities

**Please do not report security vulnerabilities through public GitHub Issues.** 

As outlined in our `SECURITY.md` file, security vulnerabilities can be reported by e-mail to the HEASARC CFITSIO/CCfits help desk at [ccfits@heasarc.gsfc.nasa.gov](mailto:ccfits@heasarc.gsfc.nasa.gov).

## Getting Help, Reporting Bugs, and Suggesting Enhancements

For bug reports, general questions, and suggesting enhancements, please contact our help desk directly at [ccfits@heasarc.gsfc.nasa.gov](mailto:ccfits@heasarc.gsfc.nasa.gov), or use the [help desk web form](https://heasarc.gsfc.nasa.gov/cgi-bin/ftoolshelp).

Reaching out to the help desk ensures your report is tracked effectively by our team. You may also open an Issue directly on GitHub.

When reporting bugs - whether via email or GitHub — please include as much detail as possible:

* Your operating system and compiler version.
* The version of CFITSIO you are using.
* Steps to reproduce the bug.
* Any relevant error messages or output.

If you are suggesting a new feature and plan to implement it yourself, please discuss it with us first (via email or a GitHub Issue) so we can ensure it aligns with the project's goals.

## Submitting Pull Requests

We gladly accept Pull Requests (PRs) for bug fixes, new features, and documentation updates. To submit a PR:

1. **Fork the repository** and create your feature or bug-fix branch from the `develop` branch.
2. **Write clean, documented code**. Please ensure your code conforms to the existing style and conventions used in the CFITSIO codebase.
3. **Test your changes**. Ensure that your changes do not break any existing functionality and, if possible, include new tests for your feature or bug fix.
4. **Update documentation**. If your PR changes user-facing functionality or the API, please update the relevant documentation.
5. **Open a Pull Request**. Provide a clear and descriptive title. Target the `develop` branch for your PR. In the description, explain what changes you made, why you made them, and link to any relevant GitHub Issues or help desk discussions.

## Pull Request Review Process

Once you submit a PR, a member of the HEASARC/CFITSIO development team will review it. 

* We may request changes or ask for clarification.
* Once the review is approved and any necessary tests pass, a maintainer will merge your PR into `develop` for inclusion in a future release.

Thank you for contributing to CFITSIO and supporting the astrophysics community!
